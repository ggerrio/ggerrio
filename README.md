## 👋 About Me

I build things that sit at the intersection of **hardware, software, and intelligence** — from ESP32 firmware talking to sensors, to full‑stack dashboards, to AI‑driven automation pipelines.

- 🔌 **IoT / Embedded Systems** — firmware, sensors, real‑time monitoring
- 🤖 **AI Engineering** — multi‑agent systems, data pipelines, automation
- 🌐 **Fullstack Development** — APIs, dashboards, admin panels, end‑to‑end apps
- 🌱 Currently exploring smarter ways to connect physical devices to AI‑powered decision systems
- 💬 Ask me about ESP32/Arduino, Flask/Laravel backends, or agent-based automation
